<h1>Hola grupo, les dejo un par de instrucciones a la hora de manejar el proyecto.</h1>

1.- CLONAR EL REPO CON GIT BASH ANTES DE EMPEZAR: Al iniciar gitbash, les recomiendo irse al directorio de "Documentos", cd documents y una vez esten ahi, peguen el siguiente codigo:

        git clone https://github.com/luv4sua/Reportes-SIP.git

2.- INSTALAR GITHUB DESKTOP: Este facilita bastante el merge y desarrollo de commits en el proyecto, es muy facil de usar, y cada que hagan un cambio, deben escribir el commit correspondiente y les saldra un boton azul para hacer merge o un push request.

3.- A la hora de hacer commits y/o pull requests, enviar un correo avisando, se que es tedioso y algo innecesario, ya que con los commits se ven los cambios y asi, pero es para tener orden estos pocos dias que nos quedan como grupo antes de la feria TP, enviar correos a:
